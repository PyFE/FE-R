# Package index

## All functions

- [`BachelierImpvol()`](https://pyfe.github.io/FE-R/reference/BachelierImpvol.md)
  : Calculate Bachelier model implied volatility
- [`BachelierPrice()`](https://pyfe.github.io/FE-R/reference/BachelierPrice.md)
  : Calculate Bachelier model option price
- [`BlackScholesImpvol()`](https://pyfe.github.io/FE-R/reference/BlackScholesImpvol.md)
  : Calculate Black-Scholes implied volatility
- [`BlackScholesPrice()`](https://pyfe.github.io/FE-R/reference/BlackScholesPrice.md)
  : Calculate Black-Scholes option price
- [`CevMassZero()`](https://pyfe.github.io/FE-R/reference/CevMassZero.md)
  : Calculate the mass at zero under the CEV model
- [`CevPrice()`](https://pyfe.github.io/FE-R/reference/CevPrice.md) :
  Calculate the constant elasticity of variance (CEV) model option price
- [`Nsvh1Choi2019()`](https://pyfe.github.io/FE-R/reference/Nsvh1Choi2019.md)
  : Calculate the option price under the NSVh model with lambda=1 (Choi
  et al. 2019)
- [`SabrHagan2002()`](https://pyfe.github.io/FE-R/reference/SabrHagan2002.md)
  : Calculate the equivalent BS volatility (Hagan et al. 2002) for the
  Stochatic-Alpha-Beta-Rho (SABR) model
- [`SpreadBachelier()`](https://pyfe.github.io/FE-R/reference/SpreadBachelier.md)
  : Spread option under the Bachelier model
- [`SpreadBjerksund2014()`](https://pyfe.github.io/FE-R/reference/SpreadBjerksund2014.md)
  : Spread option pricing method by Bjerksund & Stensland (2014)
- [`SpreadKirk()`](https://pyfe.github.io/FE-R/reference/SpreadKirk.md)
  : Kirk's approximation for spread option
- [`SwitchMargrabe()`](https://pyfe.github.io/FE-R/reference/SwitchMargrabe.md)
  : Margrabe's formula for exhange option price
